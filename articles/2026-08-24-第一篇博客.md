你好，欢迎来到我的博客！

这是一篇**示例文章**。当你把博客部署到 GitHub 后，首页会显示仓库 `articles/` 目录下的真实文章。

## 怎么发新文章

1. 在 GitHub 仓库的 `articles/` 文件夹里新建一个 `.md` 文件
2. 文件名格式：`2026-08-24-文章标题.md`（日期用于排序）
3. 文件顶部可写 Front Matter：

```markdown
---
title: 文章标题
date: 2026-08-24
category: 日常
tags: [标签1, 标签2]
cover: images/photo.jpg
---
```

## 支持的格式

- **加粗**、*斜体*、`行内代码`
- 列表、表格、引用
- 代码块自动高亮

```javascript
console.log('hello blog');
```
